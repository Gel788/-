# LUNA BIANCA — Mobile App UI

Премиальный интерактивный UI/UX-прототип мобильного приложения клиники **LUNA BIANCA** (стоматология + косметология, Москва).

## Запуск

```bash
cd luna-bianca
npm install
npm run dev
```

Откройте локальный URL Vite. Справа/ниже телефона — переключатель всех 24 экранов.

## Экраны

Splash, Onboarding, Login, Главная, Стоматология, Карта зубов, Косметология, Процедура, Врачи, Профиль врача, Запись, Визиты, План лечения, Документы, Финансы, Private Client, Бонусы, Чат, Уведомления, Профиль, Семья, Клиника, Empty states, Success/Error.

## Навигация

Нижняя панель: Главная · Запись · Визиты · Документы · Профиль

## Стек

React + TypeScript + Vite · CSS design tokens · Cormorant Garamond + Manrope
